I built the first version of this website years ago, before I knew how to program. It was one long HTML file, a bouncing-canvas animation I was
disproportionately proud of.

Recently I've started wanting a place to leave half-finished thoughts.

So this is that place. Posts will be irregular and occasionally wrong. The math figures are still drifting around in the background, because some things are worth keeping.
